# LexiStory

本项目同时维护网站和 Android / iPhone 工程。先看[本轮产品评估与改进](docs/product-audit.md)和[手机端构建说明](docs/mobile.md)。当前数据保存在本机，尚未提供账号云同步。

新用户可直接体验一篇示例；点句子只查看解析，主动点播放才朗读，支持暂停、继续、重播和语速。读完确认后才计入学习成果。

> 一款面向**考研英语**的 AI 语境式学习应用。学过的单词和语法不会学完就丢——它们会按间隔重复的节奏，被反复编织进新文章，在真实语境中复现。

## 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:3000 即可开始学习。

## 核心理念

单独背单词、单独学语法，却从不在文章里用上，等于白学。

LexiStory 把**单词本**和**语法本**接进同一套间隔重复引擎，每篇文章都是一份混合配方：

```
一篇文章 = 教材单元新词 + 到期该复习的旧词 + 测验答错的词 + 你自己导入的词
         + 本单元新语法 + 到期该复习的旧语法
```

生成前配方就摊开给你看，新学和复现分色标注。

## 核心流程

0. **30 秒词汇摸底** — 20 个词标「认识/不认识」，立刻拿到词汇量估算（对标考研大纲 5500 词），
   并且第一篇文章就用你刚说不认识的词。
1. **选择教材单元** — 考研核心词 30 单元 750 词（每词带释义），也支持人教版小学/初中，或粘贴自己的生词表。
2. **查看今日配方** — 明确告诉你这篇由几个新词、几个复习词、哪些语法组成，可点掉不想要的词。
3. **生成文章** — AI 写一篇自然融入这些内容的文章。新词配充足语境线索，复习词换个搭配自然复现。
4. **阅读学习** — 目标词高亮，点击句子看成分拆解、难词、语法讲解，并朗读发音。
5. **测验巩固** — 三道课后题。答对的词间隔拉长，答错的当天重来并排进下一篇。
6. **回看用例** — 语法本里点开任意语法点，能看到它在你读过的所有文章中的真实原句。

## 功能特性

- **混合配方生成** — 学过的词和语法按到期时间自动复现，不是学完就丢
- **间隔重复引擎** — SM-2 简化版，单词与语法共用一套调度
- **出现验证** — 校验目标词是否真的出现在正文里（含 preserved / cats 等屈折形式）；模型漏用的词不计入学习记录，会保留在复习队列
- **义项控制** — 先确定每个词本次要练的义项，避免 book 一会儿当"书"一会儿当"预订"
- **语法本 + 讲解页** — 反查每个语法点在你读过的文章中的所有原句
- **句子分析** — 成分拆解、难词音标释义、语法讲解、短语标注
- **单词本** — 到期视图、批量导入、原句反查
- **学习统计** — 词汇量增长、语法覆盖、复习热力图
- **长难句标注** — 考研阅读最大的失分点，自动识别并给出成分拆解
- **快速体验与继续阅读** — 示例无需等待；回到首页可继续未读完的文章
- **数据备份** — 导出、导入前验证与预览、失败回滚、恢复导入前数据；手机 App 支持系统分享保存

## 技术栈

- Next.js 16 + React 19 + TypeScript
- Tailwind CSS 4 + shadcn/ui（桌面侧边栏 / 移动底部导航）
- localStorage 本地持久化，带版本化迁移与自动备份
- DeepSeek API（文章生成、词义补全）
- 阿里云 DashScope（句子朗读，可选）

## AI 配置

在项目根目录创建 `.env.local` 文件：

```
DEEPSEEK_API_KEY=你的API密钥          # 必填：文章生成、词义补全
DASHSCOPE_API_KEY=你的API密钥         # 选填：句子朗读，缺省时回退到浏览器语音
```

然后重启开发服务器：

```bash
npm run dev
```
